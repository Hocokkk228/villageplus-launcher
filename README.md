# VillagePlus Launcher

Лаунчер VillagePlus для Windows и Linux. Minecraft 1.21.11 / Fabric.

Готовые сборки: [Releases](https://github.com/Hocokkk228/villageplus-launcher/releases).

- Запуск с All-in-One Optimization или без него.
- Загрузка актуальной сборки из этого репозитория с проверкой SHA-256.
- При недоступности GitHub используется последняя проверенная локальная сборка.
- Примерочная, синхронизация косметики и комнаты через Slon.

## Запуск исходников

Node.js 22+: `npm ci`, затем `npm start`.
Перед упаковкой поместите моды из последнего релиза в `bundle/mods`.
Windows: `npm run pack:win`. Linux: `npm run pack:linux`.

## Обновления сборки

`channels/stable.json` содержит версию, имена, размеры, ссылки на Release assets и SHA-256. Лаунчер скачивает сборку перед следующим запуском игры, проверяет все файлы и только после успешной проверки заменяет локальную сборку. Запущенная игра не меняется.

Миры и данные аккаунтов сюда не выгружаются. Minecraft, Java и библиотеки загружаются отдельно с источников установщика.

## Проверки и ограничения

`npm test`: установка, передача сборок, проверка хешей, отказ от повреждённых файлов и запуск без связи с обновлениями. Windows-пакет собран на Linux; запуск на Windows ещё не проверен. Интернет-комнаты и звонки с реальными аккаунтами требуют отдельной проверки. Исходный архив косметики не входит в репозиторий; каталог использует предоставленные для проекта ресурсы, авторские метаданные сохранены. Права на сторонние компоненты остаются у их авторов.
