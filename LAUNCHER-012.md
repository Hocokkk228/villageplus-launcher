# Launcher 0.1.2: комнаты и сохранённые чаты

- Убрано зависание содержимого вкладок в прозрачном состоянии после запуска Minecraft.
- Добавлены список чатов и история сообщений на этом компьютере, отдельно для каждого аккаунта SLON.
- Приглашение приходит сообщением с кнопкой «Подключиться».
- Перед приглашением хост открывает текущий мир по сети и получает реальный порт.
- Сборка передаётся из запущенного экземпляра, без обновления файлов работающего Minecraft.
- После проверки файлов создаётся игровой туннель, запускается Minecraft с выбранной сборкой и параметром quickPlayMultiplayer.
- Ошибки подключения и подготовки остаются видны в разделе комнаты.
- Для повторного подключения после закрытия туннеля нужно новое приглашение. При уже запущенном Minecraft следует закрыть его и повторно нажать «Подключиться».

Проверки: 11 тестов Node; восстановление чата и 9 переключений вкладок после запуска/скрытия; два настоящих WebRTC peer с передачей 24 013 байт и вызовом автоматического подключения. Дополнительно принудительно проверена передача через действующий внешний TURN Slon с текущего Linux-компьютера. Windows собран, запуск на Windows не проверен. Подключение двух друзей из разных сетей ещё требует проверки пользователями.
