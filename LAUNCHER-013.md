Автообновление кода лаунчера при запуске с проверкой SHA-256 и сохранением рабочей копии для запуска без интернета. Кнопку «Открыть комнату» теперь можно нажать заранее: лаунчер ждёт запуска игры и входа в одиночный мир; ожидание можно отменить. Включает сохранённые чаты и приглашение-кнопку версии 0.1.2. Встроенная сборка мода 0.50.4. Для старых лаунчеров 0.1.0–0.1.2 нужна одна установка 0.1.3: у них отсутствует код самообновления. После этого новые версии кода лаунчера подхватываются при перезапуске. Новая версия самого Electron при необходимости потребует отдельного установщика. Windows собран, запуск на Windows не проверен.

Проверки: 14 Node-тестов; Electron скачал и запустил проверенный ASAR, затем использовал его без сети; настоящий main/preload/renderer — ожидание мира и отмена; восстановление чата и вкладки при запущенной игре.
